# e-staffing for iPhone Duo

Private source build repository for the e-staffing iOS app.

GitHub Actions builds an **unsigned IPA** with **Xcode 27.1 / iOS SDK 27.1**. Do not commit passwords, authentication cookies, private certificates, or other secrets. The finished IPA must be signed separately before installation.

The build workflow verifies the exact SDK and uploads an artifact. Use **Actions → Build iPhone Duo IPA (iOS 27.1)** to inspect runs and download the result.
